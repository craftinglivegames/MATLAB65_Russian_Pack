# MATLAB 6.5 (R13) — русификатор интерфейса

Русскоязычный пакет для MATLAB 6.5 (R13) под Windows. Переводит **интерфейс программы**: главные меню, панели рабочего стола, диалоговые окна (включая «Настройки»), окно справочного браузера и стартовые сообщения окна команд.

Проверено на чистой установке MATLAB 6.5 (`C:\MATLAB6p5`) под Windows с системной локалью ru-RU. Скриншоты результата — в папке `screenshots/`.

## Что переведено

- Главное меню: «Файл», «Правка», «Вид», «Сеть», «Окно», «Справка» и все подменю.
- Панели рабочего стола: «Окно команд», «Область данных», «История команд», вкладки «Рабочая область» / «Текущий каталог», столбцы «Имя / Размер / Байты / Класс», строка состояния «Пуск | Готово».
- Диалог «Настройки» (Preferences) целиком: дерево разделов, все группы параметров, кнопки «OK / Отмена / Применить / Справка».
- Интерфейс справочного браузера: меню, панель навигации, вкладки «Содержание / Указатель / Поиск / Демонстрации / Избранное», фильтры.
- Стартовые сообщения окна команд (например, подсказка «Для начала выберите "MATLAB Help" в меню "Справка"»).
- Всего: **76 Java-бандлов ресурсов, 3854 переведённых строки** + нативный каталог `ru/xlate`.

## Что НЕ переведено (сознательно вне объёма)

- Сообщения об ошибках и предупреждения движка («Undefined function or variable…», «Warning: Divide by zero…») — они формируются нативным кодом и не читают Java-бандлы.
- Тексты самой справки (HTML-документация) — остаются английскими.
- Служебная строка «Using Toolbox Path Cache…» при запуске.
- Тулбоксы (Simulink и др.) — их интерфейсные ресурсы не входили в задачу.

## Состав архива

```
MATLAB65_Russian_Pack/
├─ java/patch/…          — 156 файлов *.properties (русские Java-бандлы)
├─ ru/xlate              — нативный русский каталог сообщений (CP1251)
├─ toolbox/local/
│  ├─ matlabrc.m         — патченный файл (включает русскую локаль)
│  └─ matlabrc.m.orig    — оригинальный файл для отката
├─ screenshots/          — скриншоты результата
└─ README.md             — этот файл
```

## Установка

1. **Сделайте резервную копию** (если патчить «вручную» без архива с `.orig`):
   - `C:\MATLAB6p5\toolbox\local\matlabrc.m` → `matlabrc.m.enbak`
   - `C:\MATLAB6p5\toolbox\local\classpath.txt` → `classpath.txt.enbak`
2. Скопируйте содержимое архива в корень установки MATLAB (в вашем случае `C:\MATLAB6p5`), **объединяя папки**:
   - `java/patch/**` → `C:\MATLAB6p5\java\patch\`
   - `ru/xlate` → `C:\MATLAB6p5\ru\xlate`
   - `toolbox/local/matlabrc.m` → `C:\MATLAB6p5\toolbox\local\matlabrc.m`
3. Убедитесь, что в `C:\MATLAB6p5\toolbox\local\classpath.txt` **до всех jar** добавлена строка:
   ```
   $matlabroot/java/patch
   ```
   (в проверенной установке она уже присутствует; без неё Java-бандлы подхватываться не будут).
4. Удалите кеш заголовков панелей, чтобы они обновились с английских на русские:
   ```
   %APPDATA%\MathWorks\MATLAB\R13\MATLAB.ini
   ```
   Просто удалите файл `MATLAB.ini` (его восстановит/пересоздаст MATLAB при следующем запуске). Если хотите сохранить английские настройки — переименуйте его в `MATLAB.ini.enbak`.
5. Запустите MATLAB. Русификация активируется автоматически: `matlabrc.m` при старте выставляет локаль `ru`, Java-интерфейс берёт русские строки из `java/patch`, нативные стартовые сообщения — из `ru/xlate`.

## Удаление (откат)

1. Закройте MATLAB.
2. Удалите папку `C:\MATLAB6p5\java\patch` и файл `C:\MATLAB6p5\ru` (вместе с `xlate`).
3. Восстановите оригинальный `matlabrc.m`: скопируйте `matlabrc.m.orig` (или ваш `matlabrc.m.enbak`) обратно в `toolbox\local\`.
4. Уберите строку `$matlabroot/java/patch` из `classpath.txt` (или восстановите `classpath.txt.enbak`).
5. При желании удалите `MATLAB.ini` — английские заголовки панелей восстановятся сами.
6. Запустите MATLAB — интерфейс снова будет английским.

## Известные особенности

- **Заголовки панелей кешируются** в `%APPDATA%\MathWorks\MATLAB\R13\MATLAB.ini`. При первом запуске после установки (а также после принудительного завершения MATLAB) они могут отображаться английскими — удалите `MATLAB.ini` и перезапустите программу.
- Пакет не трогает исполняемые файлы и jar-архивы: переводится только за счёт каталога `java/patch`, который в classpath идёт раньше всех jar. Оригинальные файлы остаются нетронутыми — откат полностью обратим.
- На машинах без прав администратора MATLAB при каждом запуске показывает служебный диалог «Registry Configuration Error» — это нормально для R13 под современными Windows и к русификации отношения не имеет.
- Если MATLAB сообщает о потере связи с менеджером лицензий — это вопрос лицензирования самой копии MATLAB, а не пакета.
